## Code Review Analysis

As part of my CS 499 capstone, I completed a code review of the original artifacts selected for enhancement. The purpose of the review was to examine the existing functionality, identify areas that could be improved, and explain the enhancements I planned to complete during the capstone.

The code review focuses on three areas of computer science:

- Software Design and Engineering
- Algorithms and Data Structures
- Databases

During the review, I examined the structure, functionality, organization, testing, security, and maintainability of the original projects. I also discussed how each planned enhancement would improve the artifact and demonstrate skills developed throughout the Computer Science program.

## Enhancement Areas

### Software Design and Engineering

For the first enhancement, I reviewed my CS 320 contact, task, and appointment services. The original project contained working service classes but did not provide a single application that allowed a user to interact with all of them together. My planned enhancement focused on integrating these services into a complete console application.

### Algorithms and Data Structures

For the second enhancement, I reviewed how the CS 320 project stored and accessed its records. I planned to expand the project by adding search and sorting functionality that made greater use of the existing collections and demonstrated additional work with algorithms and data structures.

### Databases

For the third enhancement, I reviewed my CS 340 Animal Shelter Dashboard and MongoDB CRUD project. Although the project already included MongoDB, the dashboard still relied heavily on a locally loaded CSV file for filtering. My planned enhancement focused on making MongoDB the primary source of dashboard data and expanding the available database driven search options.
